# Kahuna Agency — Landing Page

Sitio web oficial de [Kahuna Agency](https://kahuna.li), agencia de diseño y desarrollo web en Guatemala enfocada en profesionales y negocios.

## Stack

- HTML5 / CSS3 / JavaScript (ES Modules)
- Sin frameworks ni librerías externas
- Alojado en Cloudflare Pages
